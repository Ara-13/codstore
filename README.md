# فروشگاه اکانت کالاف دیوتی (COD Store)

یک وب‌اپلیکیشن ساده و کاربردی که با استفاده از فریم‌ورک **Django** (پایتون) برای خرید و فروش اکانت‌های بازی Call of Duty طراحی شده است.

## امکانات پروژه

- **لیست اکانت‌ها**: نمایش اکانت‌های موجود برای فروش با جزئیاتی مانند سطح (Level)، ریجن (هند، ایران، اروپا)، بتل‌پس، وضعیت رنک و قیمت.
- **جزئیات اکانت**: صفحه اختصاصی برای هر اکانت به همراه توضیحات کامل و گالری تصاویر آن.
- **ثبت فرم فروش**: امکان ثبت مشخصات و تصاویر اکانت توسط کاربرانی که قصد فروش اکانت خود را دارند.
- **سیستم تایید (Moderation)**: پیگیری وضعیت انتشار اکانت‌ها (در انتظار تایید مدیریت یا منتشر شده) و وضعیت فروش (موجود یا فروخته شده).
- **احراز هویت**: سیستم ورود و خروج کاربران (Login / Logout).
- **پنل مدیریت (Admin)**: پنل مدیریت پیش‌فرض جنگو برای بررسی، تایید و مدیریت تمامی اکانت‌ها و تصاویر ارسالی.

## نیازمندی‌ها

برای اجرای این پروژه، نیاز است که ابزارهای زیر را روی سیستم خود نصب داشته باشید:

- Python 3.x
- Django (نسخه ۳ یا بالاتر)
- کتابخانه Pillow (برای پشتیبانی از ImageField و آپلود تصاویر اکانت‌ها)

## نصب و راه‌اندازی در محیط توسعه (Local)

۱. **کلون کردن مخزن**:
   ابتدا پروژه را دریافت کنید و وارد پوشه آن شوید:
   ```bash
   git clone https://github.com/Ara-13/codstore.git
   cd codstore
   ```

۲. **ایجاد محیط مجازی (پیشنهادی)**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # در ویندوز: venv\Scripts\activate
   ```

۳. **نصب وابستگی‌ها**:
   فریم‌ورک جنگو و کتابخانه مدیریت تصاویر را نصب کنید:
   ```bash
   pip install django pillow
   ```

۴. **اعمال مایگریشن‌ها (Migrations)**:
   پایگاه‌داده SQLite پروژه را با مدل‌ها همگام‌سازی کنید:
   ```bash
   python manage.py makemigrations
   python manage.py migrate
   ```

۵. **ایجاد کاربر ارشد (Superuser) (اختیاری)**:
   برای ورود به پنل ادمین جهت تایید اکانت‌های ارسالی، یک کاربر ادمین بسازید:
   ```bash
   python manage.py createsuperuser
   ```

۶. **اجرای سرور لوکال**:
   سرور را راه‌اندازی کنید:
   ```bash
   python manage.py runserver
   ```
   حالا می‌توانید پروژه را در مرورگر خود از طریق آدرس `http://127.0.0.1:8000` مشاهده کنید. برای ورود به پنل مدیریت به آدرس `http://127.0.0.1:8000/admin` مراجعه کنید.

## ساختار اپلیکیشن‌ها
- `Sell/`: شامل مدل‌ها، ویوها (Views) و روت‌های مربوط به ثبت و نمایش اکانت‌های فروشی.
- `Buy/`: شامل بخش‌های مربوط به درخواست خرید اکانت‌ها.
- `codstore/`: پیکربندی اصلی پروژه و تنظیمات دیتابیس/مسیردهی (Settings & URLs).
